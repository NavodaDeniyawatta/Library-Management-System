# Library Management System  
A desktop application built in C# using Visual Studio, designed to manage library operations including book & member management, issuing and returning books.  
[Demo Video](https://youtu.be/jR6MXHtC310)  

---

## 📌 Project Overview  
This application provides a streamlined solution for libraries (or educational institutions) to manage their book inventories, members, and lending transactions. It aims to reduce manual paperwork, improve accuracy, and provide a simple but effective user interface.  
(The demo video linked above shows the full workflow of the system.)

---

## ✅ Key Features  
- User login and authentication (librarian/administrator).  
- Add, edit, delete books (title, author, ISBN, category, availability).  
- Add, edit, delete library members (name, ID, contact details).  
- Issue books to members — record date of issue, due date.  
- Return books — update inventory and status.  
- Search and filter books/members/transactions.  
- Simple dashboard showing totals (books, members, issued books etc).  
- (Optional) Fine calculation / overdue tracking (depending on your build).
